# Milestones Group HR — نسخة قابلة للتثبيت

واجهة عربية RTL لتطبيق الموارد البشرية، مع ملفات منفصلة وسهلة التعديل.

## تشغيل التطبيق محليًا

**Windows:** شغّل `start-windows.bat` ثم افتح `http://localhost:8080` في Chrome.

**macOS / Linux:** من Terminal، داخل هذا المجلد نفّذ:

```bash
chmod +x start-linux-macos.sh
./start-linux-macos.sh
```

ثم افتح `http://localhost:8080` في Chrome.

## تثبيت التطبيق من Chrome

1. افتح التطبيق من `http://localhost:8080` أو من عنوان HTTPS بعد رفع الملفات إلى استضافة آمنة.
2. سجّل الدخول، ثم اختر زر **تثبيت التطبيق** داخل الواجهة. ويمكن أيضًا استخدام قائمة Chrome ⋮ ثم **تثبيت التطبيق**.
3. سيظهر التطبيق كتطبيق مستقل على الجهاز.

> فتح `index.html` مباشرة بالنقر المزدوج لا يفعّل التثبيت؛ يلزم تشغيله على localhost أو استضافته عبر HTTPS. التطبيق يحتاج اتصالًا بالإنترنت للوصول إلى خدمات الحساب وبيانات الموارد البشرية.

## الملفات

- `index.html`: هيكل الصفحات.
- `assets/css/app.css`: تنسيقات التطبيق ودعم العربية وRTL.
- `assets/css/brand.css`: لوحة ألوان وهوية الشركة؛ الألوان الأساسية مستخرجة من الشعار (`#29235F` و`#BED73B`).
- `assets/js/app.js`: وظائف التطبيق والصفحات.
- `assets/images/milestones-full-logo.png`: الشعار الأصلي بخلفية شفافة.
- `assets/images/milestones-full-logo-light.png`: نسخة فاتحة بخلفية شفافة لتظهر بوضوح فوق الخلفيات الداكنة.
- `assets/images/app-icon-*.png`: أيقونات تثبيت التطبيق.
- `manifest.json` و`sw.js`: إعدادات تطبيق الويب التقدمي والتخزين المؤقت للواجهة.

تم حذف أقسام **المهام، العهد والأصول، المستندات، التعلم والتطوير، والتقدير والامتنان** من التنقل ولوحات المعلومات والتقارير.
