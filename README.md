# Milestones Group HR — جاهز للرفع على GitHub Pages

هذه نسخة مسطحة: **كل ملفات التطبيق موجودة في نفس المجلد بجوار `index.html`، بدون مجلدات فرعية**.

## الرفع إلى GitHub

1. فك ضغط ملف ZIP على جهازك.
2. أنشئ مستودعًا جديدًا على GitHub، ثم ارفع **كل محتويات المجلد المستخرَج** إلى جذر المستودع، وليس ملف ZIP وحده.
3. من **Settings → Pages** اختر النشر من فرع `main` ومجلد `/(root)`.
4. بعد ظهور رابط GitHub Pages، افتحه في Chrome. الرابط يعمل عبر HTTPS، وهو مناسب لتثبيت التطبيق.
5. اختر **Install app / تثبيت التطبيق** من قائمة Chrome.

## تشغيل محلي للتجربة

- Windows: شغّل `start-windows.bat`.
- macOS/Linux: شغّل `start-linux-macos.sh`.

يفتح ملف البداية الخادم المحلي والمتصفح تلقائيًا. إذا لم تفتح الصفحة، استخدم `http://127.0.0.1:8080`. التشغيل المحلي يحتاج Python 3؛ GitHub Pages لا يحتاجه.

## بنية الملفات

توجد ملفات HTML وCSS وJavaScript والصور والـmanifest والـService Worker كلها في الجذر نفسه. لا تنقل الملفات أو تغيّر أسماءها بعد الرفع حتى تعمل الروابط والتثبيت.

> التطبيق يعتمد على الاتصال بالإنترنت لخدمات الحساب والبيانات والخطوط الخارجية.
